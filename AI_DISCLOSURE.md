# Draft generative-AI disclosure for a future GEMS submission

**Status: draft, not submitted.** The official GEMS rules require a narrative disclosure describing the extent to which generative AI was used and how it contributed to the submission elements. The entrant must review, correct, and approve this draft before use; it does not replace the entrant's responsibility for accuracy, authenticity, attribution, and authorship representations.

> Generative-AI assistance was used to plan, draft, implement, review, and document this research project. An AI coding agent assisted with the H31-A feature and evaluation code, tests, source summaries, provenance records, and the project website. The candidate design is documented in the repository's preregistration; any future local results must be added to the evidence records and distinguished from competition scores. The agent did not access private test labels, submit a file, or monitor/copy the DrivenData leaderboard. The human entrant is responsible for reviewing the code and claims, confirming any additional human or software contributions, and disclosing all use relevant to the exact solution and documentation delivered.

Before any entry, replace or supplement this statement so it accurately lists the human authors' contributions, external tools or services, any other generative-AI use, and every code/data/documentation element included in that exact submission. Do not state that a model result, organizer acceptance, or score is verified unless an official artifact supports it.

Official source: [GEMS Prize Official Rules](https://docs.nlr.gov/docs/fy26osti/96647.pdf), §3.2 (Process Overview).
