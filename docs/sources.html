Provenance

How to read a claim on this site

Every claim carries its class. A class is a statement about where the evidence came from — not about how confident anyone feels.

  • OFFICIAL — direct retrieval recorded on the row's accessed date. Only the pinned organizer GitHub reference was freshly retrieved on 2026-10-25; other official links retain historical access dates.
  • OWNER-MIRROR — published in one of this project's own repositories; a hash match proves byte identity to that mirror only.
  • COMPUTED — reproduced by a script in this repository, with the artifact path recorded.
  • INFERENCE — reasoning to be tested, not a measurement.
  • USER-REPORTED — stated by the project owner; no organizer receipt in the repository.
  • TRUSTED-PEER-REVIEWED — peer-reviewed methods literature cited for a design choice; it supplies no value for this dataset.

  • The Geologic Enhanced Mapping System (GEMS) Prize Challenge — problem description OFFICIAL · DrivenData / DOE GEMS Prize · 2026-10-04
    • Metric: distance-weighted Tversky index, DTI = TPw/(TPw + alpha*FPw + beta*FNw) with alpha=0.2, beta=0.8 and a linear triangular kernel k(d)=max(1-d/300 m,0).
    • TPw = sum_g max_{x: d(x,g)<=R} p(x)k(d); FPw = sum_{x: p(x)>0} p(x)[1 - max_g k(d(x,g))]; FNw = sum_g [1 - max_x p(x)k(d(x,g))]. Transcribed from this page in the current session and implemented in src/gemsdoe31/metric.py.
    • Submission: single-band float32 GeoTIFF at EPSG:32611 and 100 m, same bounds as the training data, values between 0 and 1, data outside the bounds null or nan.
    • Test truth: faults manually identified by experts that are NOT contained in the public USGS database; after the initial prize round an expert panel uses submitted predictions to update fault labels for the whole region and submissions are rescored.
    • Provided features: training_features.tif with 19 layers (conductivity/depth to conductive base, detrended elevation and its slope, strain rates, isostatic gravity anomaly and its slope, magnetics incl. rtp/tmi with vertical and horizontal slopes and top-of-crustal magnetic source depth, earthquake density) and 1m_DEM_links.csv.
    • Prize structure printed on this page: Initial Prize Round top 5 win $10,000 each; Final Prize Round pays $100,000 / $70,000 / $40,000 / $25,000 / $15,000; one submission is selected for scoring in both rounds.
    • An official reference solution exists: https://github.com/drivendataorg/gems-prize-reference-solution
    • The page says the provided sample submission 'predicts total fault absence'; the owner-mirror copy's non-zero cells are exactly the catalogue raster, which is recorded as IR-31-TEMPLATE-CATALOGUE-CONTENT rather than silently accepted.

    Limit: Public/private leaderboard values were not accessed. The official data-download tab redirects to login in this environment.

Boundary

What this project deliberately does not do

These are limits chosen for the competition's terms and the integrity of the numbers, not omissions.

No leaderboard scraping

The DrivenData terms prohibit automatic access and manual monitoring or copying without written consent. The leaderboard is a static link for a human to open; nothing on this site is derived from it.

No uploading

Nothing in this repository submits a file. A weekly slot is scarce and the charter requires a measured margin before one is spent.

No unaudited competition claims

Competition values without exact-byte organizer receipts are USER-REPORTED. Current local results are separately labelled HOLDOUT-DTI with evaluator, positive count and CI. No organizer receipt is present.
