The central question

Why H33 may have scored well

A metric mechanism is not causal proof of a private score.

For binary dots, write T = covered-truth kernel credit, M = total nearest-truth self-credit at dots, n = emitted dots and K = truth pixels. Then

DTI = T / [0.2 × (T + n − M) + 0.8 × K]
TPw = T; FPw = n − M; FNw = K − T.

Truth credit saturates at one per truth pixel. Nearby redundant predictions keep adding false-positive mass without proportional new coverage. Spacing dots near the kernel scale can therefore be more efficient than emitting a thick ridge. Removing a dot improves DTI only when its lost truth credit is small relative to the removed cost; distance to a known trace alone does not prove that.

Re-read bytes establish H27 = D2.8 with catalogue distance >1 pixel, and H33 = D2.8 with distance >2 pixels. H33 removes exactly 2,545 H27 dots. All three share 35,483 dots beyond 300 m from the catalogue. This is catalogue-flank deletion, not an independent geophysical discovery. Equal far-field dot support does not imply equal kernel credit: removed near-catalogue dots can still cover nearby new truth.

The owner's H33 archive labels the file unscored and contains no exact-byte organizer receipt for the prompt's claimed 0.2778. Without private truth and matched receipts, neither “highest score” nor a causal gain from the deletion is independently established. The zero/NaN outside encoding is a format policy, not a geological explanation.

Can the new file beat 0.2778? Unknown. Its local proxy metric cannot be compared numerically to a user-reported live result. This run did not establish a robust holdout advantage, so the responsible answer is no promotion, not a projected leaderboard score.

Limits and next steps

What would justify another attempt

No fourth experiment in this session. Literal registry-overlap STOP; negative results are deliverables.

  1. Resolve the protocol’s dense-control degeneracy without silently exempting the registered lattice. Within its interior, any new method’s dots pass within 3 pixels, so the literal rule blocks this lane regardless of geology. Only an explicitly revised future protocol could change that criterion.
  2. Resolve magnetic-texture specificity. Synthetic checks show that undisplaced anisotropic fabric can also trigger a max-over-orientations detector. Do not label its response as measured fault slip.
  3. Design a new preregistration for reciprocal, across-window displacement consistency and a lithologic-contact/flight-line null, reserving fresh confirmation data/draws and never tuning on them. No confirmation was run in this session.
  4. Rebuild the strong legacy comparator under the shared whole-component protocol; estimate the new method's dependence range before claiming it beats the current best.
  5. Require a positive paired lower confidence bound, fresh confirmation and an independent off-catalogue win before the separate selector considers a slot.
  6. Keep raw inputs untracked/ignored and establish organizer-authenticated format/data provenance; attach exact-byte organizer receipts before recording live scores.
